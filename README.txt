タイピング冒険録 v2.7 — GitHub Pages 公開用

【新機能】60秒タイムアタックモード
・単語のみ出題、文章問題なし
・0〜4問：2〜4文字、5〜9問：5〜6文字、10〜14問：7〜8文字、15〜19問：9〜10文字、20問以上：11文字以上
・最初から60秒。1問クリアごとにカウントし、5問クリアごとに次の段階へ
・途中終了の記録はランキング対象外
・ローマ字・ゲーム内かなフリック両対応
・タイムアタック専用ベスト10（クリア数優先、同数時はスコア順）
・フリー／冒険モード、392問、称号20種、既存ランキングは維持

【公開方法】ZIP内のindex.htmlをGitHub Pagesにアップロードしてください。
【保存】同一ブラウザーのlocalStorageに自動保存。バックアップ機能はありません。
